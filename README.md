What have you learned ?

I have learned how to use Git for version control, specifically how to track changes, manage different versions of a project, and collaborate using branches.

I now understand the importance of a professional workflow using GitHub, including creating repositories, pushing code, and managing Pull Requests.

Challenges faced and how you overcame them :

Initial Identity Setup: I encountered an "Author identity unknown" error at the beginning. I resolved this by correctly configuring my global user email and name using the git config command.

Merge Conflicts: I faced a conflict when two branches modified the same line in profile.txt. I overcame this by manually editing the file on GitHub, removing the conflict markers, and choosing the final version of the text.

Synchronization Issues: I had trouble pushing my local files because the remote repository already contained a README file. I fixed this by using git pull --rebase to sync both repositories before pushing again.

How does Git/GitHub help in collaboration ?

Git allows multiple team members to work on the same project simultaneously through branching, which prevents them from overwriting each other's work.

GitHub’s Pull Request feature is essential for code review, allowing team members to discuss and approve changes before they are merged into the main project, ensuring better code quality.
